部署至 GitHub Pages 指南

本專案為完全自包含的單一 HTML 檔案，無需任何後端伺服器或編譯流程，非常適合免費託管於 GitHub Pages：

  1. 建立儲存庫 (Repository)：
    登入 GitHub，點擊右上角「New Repository」，輸入名稱（例如 games-schedule-2026），設定為 Public。
  2. 上傳 HTML 檔案：
    點擊本網頁右上角的「下載 index.html」按鈕，取得 index.html。接著在 GitHub 倉庫頁面點選「Add file」→「Upload files」，將檔案上傳至倉庫根目錄並 Commit。
  3. 啟用 GitHub Pages：
    在該儲存庫上方點選 Settings → 左側導覽列點選 Pages。
  4. 設定分支與來源：
    在「Build and deployment」下的 Branch 選擇 main（或 master），資料夾保持 / (root)，按 Save。
  5. 完成與訪問：
    等待約 1~2 分鐘，重新整理頁面即可看到專屬公開網址（例如：https://你的帳號.github.io/games-schedule-2026/）！
